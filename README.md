面向首次操作的安装人员，包含解压、接线实拍、USB 调试、平台对应安装入口、macOS 安全放行、终端确认及安装完成检查。

适用工具包：`XR-Installer-Mac-1.1.0-prod-20261016-170742`，App 1.1.0 / 262891027。

两份独立教程分别维护：`index.html` 为 Mac 教程，`windows.html` 为 Windows 教程。各用独立链接，不合成一个操作流程，也不在页面提供平台切换。原 Mac 及 `#allow` 链接保持有效。GitHub Pages 使用 `main` 分支根目录。

Mac 图 1 为用户提供的 Finder 截图；图 2、图 3 直接引用 Apple 官方图片，并在页面注明来源。安全放行步骤依据 [Apple 官方帮助](https://support.apple.com/zh-cn/102445)。官方图片需要联网加载。接线照片、Windows 文件列表来自用户提供的 Windows Word 教程；终端提示重排为文字示意，不发布原截图中的设备序列号与个人本地路径。
