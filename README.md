# XR 头环 App 安装图文指引

面向首次操作的安装人员，包含解压、接线实拍、USB 调试、平台对应安装入口、macOS 安全放行、终端确认及安装完成检查。

适用工具包：`XR-Installer-Mac-1.1.0-prod-20261016-170742`，App 1.1.0 / 262891027。

Windows 与 Mac 的教程正文集中在同一个 `index.html` 中，顶部常驻按钮可切换平台；两端的安装步骤、实际截图和标注分别保留。切换后从所选平台的教程开头开始。`?platform=windows` 可直接打开 Windows，默认打开 Mac。原 Mac 的 `#allow` 等锚点保持有效，旧 `windows.html` 仅作兼容跳转。GitHub Pages 使用 `main` 分支根目录。

Mac 图 1 为用户提供的 Finder 截图；图 2、图 3 直接引用 Apple 官方图片，并在页面注明来源。安全放行步骤依据 [Apple 官方帮助](https://support.apple.com/zh-cn/102445)。官方图片需要联网加载。接线照片、Windows 文件列表来自用户提供的 Windows Word 教程；Windows 命令行图片使用用户原 Word 教程的 5 张实际截图，保留原有红框标注。

此仓库只发布操作说明及教程截图，不包含安装包、APK、ADB、完整运行日志或私有配置。Mac 已有一次实际覆盖安装及进程核验记录；不能据此认定新设备首次初始化或业务验收已完成。

Mac 教程现使用用户提供的 4 张实际终端截图，依次展示设备选择、设备确认、覆盖安装确认及安装完成；原图不改动，网页叠加红框标注。本次设备已有 Device Owner，所以首次设置仅保留条件说明。旧模拟素材保留在历史资源中，但当前教程不再引用。
